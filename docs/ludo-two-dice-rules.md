# NeaRer Royal Double Dice rules

NeaRer keeps two visible dice. Players can use them separately or choose the optional combined-total move.

- Roll two six-sided dice together.
- By default, each die is a separate movement allowance: use them in either order, on one token twice or on two different tokens.
- Optional combined move: select **Combine both dice** to move one eligible token by the sum (for example, 6 + 2 = 8) in one direction.
- The combined total does not act as a third die and consumes both dice for that turn.
- A token leaves its yard only when an individual die shows 6; a combined total cannot release a token.
- A combined move is available only when at least one token can legally travel the full total without exceeding the home entry.
- Re-evaluate legal moves after the first separate die, because a move can change which tokens can use the second.
- An unusable die is automatically forfeited; a playable die must not be silently discarded.
- A double six grants a bonus turn after the current pair is resolved.
- Exact home entry and the selected match's safe-square/capture rules remain in force.

This is a configurable NeaRer house-rule option, not a claim that every Nigerian Ludo table uses identical rules. Explain the two separate choices clearly before a match begins.
