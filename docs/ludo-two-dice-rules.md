# NeaRer Royal Double Dice rules

The first NeaRer two-dice ruleset uses two independent six-sided dice.

- Roll both dice together; each die is a separate movement allowance.
- Use the dice in either order, on one token twice or two different tokens.
- Never add the values together into one move.
- A token leaves its yard only when an individual available die shows 6.
- Re-evaluate legal moves after the first die, because a move can change which tokens can use the second.
- An unusable die is automatically forfeited; a playable die must not be silently discarded.
- A double six grants a bonus turn after the current pair is resolved.
- Exact home entry and the existing safe-square rules remain in force.

This is a defined NeaRer house ruleset, not a claim that all regional Ludo tables use identical rules. The in-game Rules panel should explain the sequence before a match begins.
